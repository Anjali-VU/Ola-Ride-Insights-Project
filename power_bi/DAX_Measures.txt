OLA RIDE INSIGHTS - POWER BI DAX MEASURES
Create these measures after loading data table named ola_bookings.


Total Bookings = COUNT(ola_bookings[Booking_ID])

Successful Bookings = CALCULATE([Total Bookings], ola_bookings[Booking_Status] = "Success")

Successful Booking % = DIVIDE([Successful Bookings], [Total Bookings], 0)

Customer Cancelled = CALCULATE([Total Bookings], ola_bookings[Booking_Status] = "Canceled by Customer")

Driver Cancelled = CALCULATE([Total Bookings], ola_bookings[Booking_Status] = "Canceled by Driver")

Driver Not Found = CALCULATE([Total Bookings], ola_bookings[Booking_Status] = "Driver Not Found")

Total Successful Booking Value = CALCULATE(SUM(ola_bookings[Booking_Value]), ola_bookings[Booking_Status] = "Success")

Total Booking Value = SUM(ola_bookings[Booking_Value])

Average Ride Distance = AVERAGE(ola_bookings[Ride_Distance])

Total Ride Distance = SUM(ola_bookings[Ride_Distance])

Average Customer Rating = AVERAGE(ola_bookings[Customer_Rating])

Average Driver Rating = AVERAGE(ola_bookings[Driver_Ratings])

Cancellation Rate = DIVIDE([Customer Cancelled] + [Driver Cancelled], [Total Bookings], 0)

Ride Volume = [Total Bookings]
